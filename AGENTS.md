## Lessons / Traps (IMPORTANT)
1. **NEVER mount a Railway volume at `/app`** — shadows image app code → `ENOENT /app/package.json` crash. Mount at subpath like `/app/data`.
2. **Do NOT ship a `.env` in `railway up` source** — Directus's env loader lets the baked file override Railway process env. Keep secrets ONLY in Railway env vars.
3. `railway redeploy` re-runs the LATEST deployment (env vars apply); `railway service restart` fails with "Deployment is not restartable". Use `railway up` for a fresh deployment.
4. `railway up` in an unlinked folder creates a NEW project — always pass `-p <projectId> -e production -s <serviceId>` or link first.
5. Uploads/media now live in the durable volume at `/app/data/uploads` (`STORAGE_LOCAL_ROOT`) — deploy source no longer ships `uploads/` (dead weight). Directus storage root env var is `STORAGE_LOCAL_ROOT`, NOT `UPLOADS_LOCATION`.
6. **Postgres bootstrap**: `directus start` on an EMPTY Postgres crashes (no tables). Start script MUST be `directus bootstrap && directus start`. License: fresh DB has no license_token so Directus tries online activation → `FATAL: Activation limit exceeded`. `restore-license.js` replays the encrypted key/token into `directus_settings` so it takes the verify path instead.
7. **Postgres has no public proxy** — `postgres.railway.internal` only resolves inside Railway. No local pg_dump/psql; backups run in-network via the `zru-pg-backup` cron service. pg_dump client version must match server (18.x) or you get "server version mismatch".
8. **Railway cron services** (e.g. backups) only spin up at the scheduled time — SFTP/volume-file access only works while a cron container is alive. Volume backup APIs (`volumeInstanceBackup*`) are paid-gated on Hobby — use a cron service instead.
9. **Railway GraphQL gotchas**: `railway variable set "K=V"` (not `variables --set`); cron `*/5` is the minimum interval (error "Minimum interval between cron executions is 5 minutes"); `serviceInstanceUpdate` returns Boolean (no selection set allowed); pass `-s <serviceId>` with `-p` + `-e production` for non-linked service queries.
10. **`.vercelignore` globs are case-insensitive on Windows** — the old `Gallery/` rule silently excluded `public/images/gallery/` from every deployment (hero + gallery images 404'd). Anchored: `/Gallery/`. Check .vercelignore before adding public/ asset folders.
